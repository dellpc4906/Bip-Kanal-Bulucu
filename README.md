# 📱 BiP Kanal Bulma Programı

BiP mesajlaşma platformu üzerindeki kanalları ve içerikleri kullanıcıların çok daha hızlı, rahat ve organize bir şekilde bulmasını sağlayan, web tabanlı bir arama ve keşif aracıdır.

## 🚀 Özellikler
* 🔍 **Hızlı Arama:** Aradığınız kanalları anında filtreleyin.
* 📂 **Kategorilendirme:** İlgi alanınıza göre kanalları listeyin.
* 💻 **Kullanıcı Dostu Arayüz:** Modern, sade ve mobil uyumlu (responsive) tasarım.
* ⚡ **Hafif ve Hızlı:** Pure (Vanilla) JavaScript yapısı sayesinde tarayıcıda anında çalışır.

## 🛠️ Kullanılan Teknolojiler
Bu proje tamamen web standartları kullanılarak geliştirilmiştir:
* **HTML5** - Sayfa yapısı ve semantik içerik
* **CSS3** - Modern ve şık görsel tasarım
* **JavaScript (ES6+)** - Dinamik arama ve filtreleme fonksiyonları

## 📦 Kurulum ve Çalıştırma
Projeyi yerel bilgisayarınızda çalıştırmak oldukça basittir:

1. Bu depoyu bilgisayarınıza indirin (klonlayın):
   ```bash
   git clone (https://github.com/Bip-Kanal-Bulucu/)
   ```
2. Proje klasörüne gidin.
3. `index.html` dosyasına çift tıklayarak tarayıcınızda hemen çalıştırın!
